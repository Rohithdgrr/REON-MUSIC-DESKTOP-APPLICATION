# Keyboard Shortcuts

## Playback

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `Ctrl + →` | Next Track |
| `Ctrl + ←` | Previous Track |
| `→` | Seek forward 5 seconds |
| `←` | Seek backward 5 seconds |
| `Ctrl + ↑` | Volume up |
| `Ctrl + ↓` | Volume down |
| `M` | Mute / Unmute |
| `S` | Toggle Shuffle |
| `R` | Cycle Repeat mode (off → all → one) |

## Navigation

| Key | Action |
|-----|--------|
| `Ctrl + H` | Go to Home |
| `Ctrl + F` | Go to Search |
| `Ctrl + L` | Go to Library |
| `Ctrl + D` | Go to Favorites |
| `Q` | Toggle Queue panel |
| `/` | Focus Search input |

## Application

| Key | Action |
|-----|--------|
| `Ctrl + ,` | Open Settings |
| `Ctrl + /` | Keyboard Shortcuts reference |
| `Escape` | Close panels / blur input |

## Media Keys

| Key | Action |
|-----|--------|
| `MediaPlayPause` | Play / Pause |
| `MediaTrackNext` | Next Track |
| `MediaTrackPrevious` | Previous Track |
| `MediaStop` | Stop |

## Notes

- Shortcuts work globally when the app is focused
- Input fields (search, text inputs) intercept shortcuts — press `Escape` to blur and re-enable global shortcuts
- `Ctrl` includes the `Cmd` key on macOS
