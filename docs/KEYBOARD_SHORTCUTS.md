# Keyboard Shortcuts

## Playback Controls

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `→` | Seek forward 5 seconds |
| `←` | Seek backward 5 seconds |
| `Shift + →` | Next track |
| `Shift + ←` | Previous track |

## Volume Controls

| Key | Action |
|-----|--------|
| `↑` | Volume up |
| `↓` | Volume down |
| `M` | Mute / Unmute |

## Tips

- Keyboard shortcuts work anywhere in the app (except when typing in search)
- Hold Shift with arrow keys to skip tracks instead of seeking
- Press M to quickly mute/unmute audio
